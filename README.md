# 工时助手

Windows 本机工时助手，支持钉钉扫码登录公司 OA、国家节假日及调休识别。

## 下载与更新

[下载安装包](https://github.com/sillenthill0219/worktime-report/releases/latest) · [更新记录](https://github.com/sillenthill0219/worktime-report/releases)

首次使用请下载 Release 中的 `WorktimeAssistant-Setup-1.3.5.exe`，安装后打开桌面快捷方式。

已经使用旧版：打开“版本与更新”，将更新仓库设为 `sillenthill0219/worktime-report`，然后依次检查更新、下载新版、安装更新。升级后重新打开软件。

若旧版在线升级失败，可运行完整安装包覆盖安装；本机登录、账户设置和工时记录保留。

## 1.3.5 更新内容

- 更新地址切换至此个人仓库。
- 缩小账户姓名和软件名称，显示版本更新说明。
- 保留钉钉扫码登录，以及2026年国家放假和补班安排识别。
- 支持年度节假日数据缓存、空闲端口启动和 SHA-256 校验更新。

## 本机数据

账户、登录会话和工时数据保存在当前 Windows 用户的本机应用数据目录，不上传到本仓库。

此仓库目前用于安装包和更新发布，安装包请在 Releases 中下载。
